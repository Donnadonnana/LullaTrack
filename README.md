👶 LullaTrack

LullaTrack is a modern baby tracking application designed to help parents log daily sleep and feeding activities while providing meaningful insights into their baby’s routines.

Built with React, TypeScript, Redux Toolkit, and Material UI, the project focuses on creating a clean, intuitive user experience with a scalable architecture that can easily evolve into a full-stack SaaS application.

🚧 Status: Frontend UI complete. Backend integration with Node.js, Express, and Firebase is currently in progress.

⸻

✨ Features

📊 Dashboard

* Daily sleep and feeding summaries
* Weekly trends and insights
* Helpful parenting tips
* Baby profile overview

😴 Sleep Tracking

* Log naps and night sleep
* Track:
    * On bed time
    * Fell asleep time
    * Wake time
    * Pick up time
* Automatic wake window calculation
* Daily sleep summaries
* Date navigation
* Multiple baby support

🍼 Feeding Tracking

Supports both:

* Breastfeeding
* Bottle feeding

Track:

* Feeding duration
* Bottle amount
* Milk type
* Breast side
* Notes

👶 Baby Management

* Multiple baby profiles
* Quick baby switching
* Individual records for each baby

🎨 User Experience

💡 Why I Built This

As a new parent, I found myself constantly tracking my baby’s sleep and feeding using spreadsheets and handwritten notes. Existing apps either felt overly complicated or lacked the flexibility I wanted.

LullaTrack began as a solution to a real problem I experienced every day. At the same time, it serves as a portfolio project where I can demonstrate scalable frontend architecture, reusable React components, thoughtful UX, and production-style application design.
